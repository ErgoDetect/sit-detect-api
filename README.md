# Erogo Detect Api

## 🚀 Quick Start

### 1. Clone the repository

```bash
git clone https://github.com/ErgoDetect/sit-detect-api
cd sit-detect-api
```

### 2. Create .env file

Copy the example environment file:

```bash
cp .env.example .env
```

And edit values.

### 3. Create .env file

Run with Docker

```bash
docker-compose up --build
```
